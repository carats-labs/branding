The short version.

Carats is a server-rendered web framework for Bun. It sends the page as it is: no client bundle to grow, no hydration to wait on, no JavaScript between a visitor and the content.

Approved copy

The project reached v1.0 with a single argument: most of what a modern site ships is excess. Carats renders on the server, returns finished HTML, and measures the result against the field's strongest contender on the same five-route application.

Use the descriptions below as written. They are kept short on purpose, and every figure mentioned is drawn from the public benchmark at carats.dev.

ExtendedFull boilerplate

Carats is a server-rendered web framework for Bun. Its premise is simple: send the page as it is. There is no client bundle to grow and no hydration to wait on. On a measured five-route application, Carats reports 3,828 bytes of JavaScript against 173,344 bytes for Next.js, a 28× smaller build output, and a throughput ceiling of 4,256 requests per second. The framework is at v1.0, installed with bun create carats, and documented at docs.carats.dev.

Benchmark context: Carats on Bun 1.3.12, Next.js on Node v24.13.1. Recorded 29 September 2026. Figures are reported by Carats.

Clear space

Keep a margin of at least one quarter of the mark's height on every side. Nothing should enter that space.

Minimum size

24 px for screen use. 12 mm in print. Below that, the facet detail stops reading.

Do not

Do not recolour, rotate, outline or add effects. Do not place either file on a background that fights its contrast.
